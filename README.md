# 定时关机

一个窗口，设个时间，到点关机。零第三方依赖，只用 Python 标准库。

## 用法

双击 `autoshutdown/启动.bat`，或者：

```bash
python autoshutdown/app.py
```

界面上两种模式：

- **倒计时** —— 从现在起过多久关机。默认 1 小时 30 分。
- **指定时刻** —— 关在某个钟点。若该时刻今天已过，自动顺延到明天。

大号数字既是显示也是输入：直接点进去打字，或者鼠标滚轮上下滚、方向键上下调，越界会回绕。下面三个预设按钮一键填 30 分 / 1 小时 / 2 小时。

按「开始」定时。数字随即变琥珀色并开始倒数，冒号每秒脉冲一次；不足一小时自动切成「分 / 秒」显示。按「取消」撤销。

## 关机怎么执行的

倒计时交给 Windows 自带的 `shutdown.exe /s /t <秒>`，不是程序自己 sleep。这意味着：

- **关掉窗口不影响关机**，到点照样执行。想撤销就重开程序按「取消」，或者命令行 `shutdown /a`。
- 程序崩了、被强杀了，关机计划依然有效。

取消用 `shutdown.exe /a`。没有待执行的关机时该命令返回 1116，代码里当成正常情况处理，不报错。

## 跑测试

```bash
cd autoshutdown && python -m unittest discover -p "test_*.py"
```

35 个测试，全部只用标准库 `unittest`，不需要装 pytest。关机命令在测试里被替换成假的执行器，不会真的关机。

## 文件

| 文件 | 作用 |
| --- | --- |
| `shutdown_timer.py` | 纯逻辑：目标时刻计算、剩余时间格式化。不碰界面和系统调用。 |
| `power.py` | 调 `shutdown.exe` 排定/取消关机。执行器可注入，便于测试。 |
| `app.py` | tkinter 界面。 |

分三层是为了让时间计算能被直接测到，跨午夜、时刻已过、零时长这些边界都有覆盖。
