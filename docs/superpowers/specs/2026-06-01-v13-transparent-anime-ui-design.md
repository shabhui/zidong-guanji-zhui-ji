# AutoShutdown v1.3 透明轻二次元 UI 设计

## 背景

AutoShutdown v1.2 已经包含电源动作、倒计时、指定时间、任务中心、网络闲置触发、进程退出触发、自动关闭被监控程序、执行前脚本和偏好设置。现有主窗口采用单页滚动卡片布局，功能继续增加后显得臃肿，用户需要上下滚动寻找模块。

v1.3 的目标是做一次界面结构和视觉风格升级：使用透明玻璃和轻二次元氛围，让界面更清爽，同时通过侧边导航降低信息密度。

## 目标

- 将主窗口升级为“左侧导航 + 右侧内容区”的模块化布局。
- 使用透明轻二次元风格：粉紫蓝渐变、玻璃卡片、柔和光晕、少量星光/樱花式点缀。
- 减少单屏信息堆叠，让每个功能模块只在需要时显示。
- 保留当前全部功能和业务逻辑，不改变触发/执行动作的安全流程。
- 发布 v1.3 GitHub Release，上传 `AutoShutdown-v1.3-win-x64.zip`。

## 非目标

- 不新增新的业务功能。
- 不引入外部 UI 框架或图片资源。
- 不使用 emoji 作为结构性图标。
- 不真实测试关机/重启；验证使用构建和安全动作建议。

## 视觉方向

关键词：

- 半透明玻璃
- 粉紫蓝渐变
- 柔和光晕
- 轻二次元装饰
- 桌面工具可读性
- 圆角、细边框、低对比阴影

建议颜色：

- 背景深层：`#151226`、`#241B3F`
- 玻璃面板：半透明白/紫，如 `#22FFFFFF`、`#33B779FF`
- 主色：`#B779FF`
- 副色：`#79D8FF`
- 点缀粉：`#FF8ACF`
- 成功：`#7DFFC4`
- 警告：`#FFD166`
- 危险：`#FF5C8A`
- 文字主色：`#FFF7FF`
- 文字次色：`#CDBFEA`
- 边框：`#55FFFFFF`

字体继续使用 `Microsoft YaHei UI`，保证中文桌面环境稳定。标题可通过字重、字号和渐变强调，而不是更换外部字体。

## 布局结构

窗口建议从 `600 x 720` 调整为约 `900 x 660`，保留无边框、透明窗口和托盘按钮。

整体结构：

```text
┌─────────────────────────────────────────────┐
│ 顶部：AutoShutdown v1.3 / 当前状态 / 窗口按钮 │
├──────────────┬──────────────────────────────┤
│ 左侧导航      │ 右侧当前模块内容                │
│              │                              │
│ 总览          │ 只显示当前选中模块              │
│ 定时          │                              │
│ 任务          │                              │
│ 智能触发      │                              │
│ 脚本          │                              │
│ 设置          │                              │
└──────────────┴──────────────────────────────┘
```

左侧导航固定可见，右侧模块通过 `Visibility` 切换。避免多层窗口和复杂路由，符合当前 WPF 代码结构。

## 模块划分

### 总览

总览页放最常用、最需要快速确认的信息：

- 当前选择的电源动作。
- 当前计划状态卡。
- 剩余时间 / 目标时间。
- 快捷倒计时按钮：15 分钟、30 分钟、1 小时、2 小时。
- 立即执行当前动作。
- 暂停/恢复、取消任务。

总览不显示网络闲置、进程退出、脚本等高级配置，只显示当前状态和快捷入口。

### 定时

定时页包含：

- 倒计时模式。
- 指定时间模式。
- 重复规则。
- 启动倒计时 / 启动定时按钮。

保留当前倒计时和指定时间行为。

### 任务

任务页包含：

- 保存当前为任务。
- 运行最近启用任务。
- 任务列表。
- 启用/禁用、应用、删除操作。

### 智能触发

智能触发页包含：

- 网络闲置触发。
- 进程退出触发。
- 自动关闭被监控程序设置。

进程退出触发仍复用当前逻辑：程序曾经出现后，数量变成 0 才触发电源动作提醒流程。

### 脚本

脚本页包含：

- 执行前脚本路径。
- 选择脚本。
- 启用/关闭脚本。
- 超时秒数。
- 脚本状态。

### 设置

设置页包含：

- 提醒提前时间。
- 强制关闭应用。
- 开机自动启动。

## 交互设计

- 点击左侧导航项后切换右侧模块。
- 当前导航项使用粉紫渐变背景、细边框和轻微发光。
- 非当前导航项使用透明背景，悬停时显示淡色玻璃层。
- 模块切换使用轻微淡入和 8-16px 上移动画，时长 180-260ms。
- 连续背景光斑动画保持轻微，不抢占注意力。
- 危险动作继续使用红色，和普通主按钮区分。
- 所有可点击控件保持足够高度和清晰状态。

## 实现策略

### DarkTheme.xaml

更新主题资源：

- 新增/调整透明玻璃色、粉紫蓝渐变、柔和阴影。
- 让 `CardBorder` 和 `GlassPanel` 更通透。
- 新增导航按钮样式或复用 Border 动态设置。
- 保持文字对比度，避免过度透明导致不可读。

### MainWindow.xaml

重构布局：

- 外层仍保留背景渐变和光斑。
- 顶部 header 缩短，减少垂直占用。
- 内容区改成两列：左侧导航、右侧内容。
- 将现有卡片移动到对应模块面板中。
- 状态卡在总览页显示；如果任务运行中，也允许其他模块切换时顶部状态摘要可见。

### MainWindow.xaml.cs

新增：

- 当前模块枚举或字符串状态。
- 导航点击事件。
- `ShowSection(...)` / `UpdateNavigationUI()`。
- 模块切换动画。

尽量保留现有控件名称，避免大规模改业务逻辑。现有事件处理器继续工作。

## 发布 v1.3

实现完成后：

1. 构建：`dotnet build "AutoShutdown/AutoShutdown.csproj"`。
2. 发布：`dotnet publish ... -o "AutoShutdown/publish"`。
3. 打包：`AutoShutdown/AutoShutdown-v1.3-win-x64.zip`。
4. 创建 GitHub Release `v1.3` 或更新同名 Release 资源。
5. 推送代码到 `main`。
